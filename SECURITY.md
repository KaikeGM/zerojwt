# Security Policy

## Supported Versions

Only the latest release of `zerojwt` receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.3.x   | :white_check_mark: |
| < 1.3.0 | :x:                |

## Reporting a Vulnerability

We take the security of `zerojwt` seriously. If you discover a security vulnerability, please report it responsibly:

1. **GitHub Private Vulnerability Reporting (Preferred):**  
   Use GitHub's built-in [Private Vulnerability Reporting](https://github.com/KaikeGM/zerojwt/security/advisories/new) on this repository.
2. **Email:**  
   If you cannot use GitHub Security Advisories, send an email to `kaikegmds@gmail.com` with:
   - A description of the issue;
   - Steps to reproduce or a minimal proof of concept (PoC);
   - Potential impact.

Please **do not** open public issues or pull requests for security vulnerabilities until they have been reviewed and addressed.

## Response Process

- We will acknowledge receipt of your report within 48 hours.
- We will evaluate the report, verify the vulnerability, and prepare a fix.
- A patched release and CVE advisory (if applicable) will be coordinated.
